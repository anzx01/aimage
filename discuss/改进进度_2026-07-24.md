## 已确认的关键决策
- **架构方向 A**：后端 FastAPI 为唯一可信服务端，前端只做 UI + Auth + 只读；所有敏感写（建项目/扣费/购买/退款/生成）走后端。
- **数据表真源**：`profiles`（用户）/ `credit_transactions.transaction_type` / `projects.project_type`。已删 `database/` 旧 `users` schema。
- **鉴权基线**：Supabase 原生 session token（`supabase_admin.auth.get_user`）。废弃后端自建 JWT / `security.py` / `python-jose` / `passlib`。
- **积分机制**：移除隐晦的"插入任务即自动扣费"触发器，改为显式 RPC（`deduct_user_credits` / `refund_user_credits`，仅 `service_role` 可执行），后端服务层统一调用。
- **范围**：P0 + P1 + P2 全量。Seedance 密钥由用户后续提供。
